RAFAEL RIBEIRO RUN 42K — PWA

1. Publique o conteúdo desta pasta em um endereço HTTPS.
2. No iPhone, abra esse endereço no Safari.
3. Toque em Compartilhar > Adicionar à Tela de Início.
4. Abra pelo novo ícone para usar em modo de aplicativo.

Arquivos:
- index.html: painel de treino
- manifest.webmanifest: configuração do app
- sw.js: cache/offline básico
- icons/: ícones do app
